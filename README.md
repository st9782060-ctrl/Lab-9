# Lab-9
# Практичне заняття (ЛР 8): Одновимірні масиви та генерація випадкових чисел

**Тема:** Опрацювання елементів одновимірних масивів у C++ із використанням генератора псевдовипадкових чисел (`srand`, `time`, `rand`).

## Виконані завдання

1. **Задача 3 (`task_3`):** заповнення масиву унікальними випадковими числами, пошук мінімального та максимального елементів і їх взаємна заміна.
2. **Задача 4 (`task_4`):** генерація випадкового масиву, введення числа $A$ з клавіатури та підрахунок кількості елементів, більших за $A$.
3. **Задача 5 (`task_5`):** генерація масиву унікальних випадкових чисел та знаходження другого за величиною елемента.
4. **Задача 6 (`task_6`):** генерація випадкового масиву та пошук номера першого нульового елемента (або виведення повідомлення про його відсутність).

## Висновок
Під час виконання завдань було засвоєно принципи ініціалізації генератора випадкових чисел функцією `srand(time(0))`, формування випадкових значень у заданому діапазоні за допомогою `rand()` та типові алгоритми пошуку й перестановки елементів у одновимірних масивах.
